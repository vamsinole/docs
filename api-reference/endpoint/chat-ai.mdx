---
title: Create Chat Assistant
api: 'POST https://prod-contactswing-fastapi-962560522883.us-central1.run.app/v2/new_assistants'
description: Create web chat-based AI assistants for website integration and customer support.
---

### Authorizations
<ParamField 
  header="Authorization" 
  type="string" 
  required
>
Enter your ContactSwing JWT Bearer token.
</ParamField>

### Request Body

<ParamField path="name" type="string" required>
Assistant display name. Example: `"My Chat Assistant"`
</ParamField>

<ParamField path="type" type="string" required>
Assistant type: `"CHAT"`
</ParamField>

<ParamField path="model" type="string" required>
LLM model: `"cw-llm-1"`
</ParamField>

<ParamField path="api_keys" type="array">
API key configuration `[]`
</ParamField>

<ParamField path="instructions" type="string" required>
Detailed agent instructions and restaurant ordering guidelines
</ParamField>

<ParamField path="prompts" type="object">
Agent prompts with `agent` and `goal` fields
</ParamField>

<ParamField path="kb_id" type="string">
Knowledge base ID
</ParamField>

### Chat Customization

<ParamField path="additional_settings.ChatbotCustomization.brandName" type="string">
Brand name. Example: `"ContactSwing AI"`
</ParamField>

<ParamField path="additional_settings.ChatbotCustomization.logoUrl" type="string">
Logo URL
</ParamField>

<ParamField path="additional_settings.ChatbotCustomization.greetingText" type="string">
Welcome message. Example: `"Hello welcome back"`
</ParamField>

<ParamField path="additional_settings.ChatbotCustomization.tagline" type="string">
Tagline. Example: `"Contactswing"`
</ParamField>

<ParamField path="additional_settings.ChatbotCustomization.initialMessage" type="string">
First message. Example: `"Hi, I'm Ashley 👋 Welcome to ContactSwing AI!"`
</ParamField>

<ParamField path="action_ids" type="array">
Linked action IDs `[]`
</ParamField>

### Response

**201 Created** - Chat assistant created successfully

<ResponseField name="ctx_id" type="string">Request context ID</ResponseField>
<ResponseField name="data" type="object">
  <ResponseField name="assistant_id" type="string">New assistant ID</ResponseField>
  <ResponseField name="name" type="string">Assistant name</ResponseField>
</ResponseField>

**400 Bad Request** - Invalid chat configuration

**401 Unauthorized** - Invalid token
