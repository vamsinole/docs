---
title: Create Call
api: 'POST https://prod-contactswing-fastapi-962560522883.us-central1.run.app/v2/_call'
description: Create call API that supports both v1 and v2 versions.
---

### Authorizations
<ParamField 
  header="Authorization" 
  type="string" 
  required
>
Enter your ContactSwing JWT Bearer token.
</ParamField>

### Request Body

<ParamField path="version" type="string">
API version: `"v1"` (Twilio) | `"v2"` (LiveKit SIP). Default: `"v1"`
</ParamField>

<ParamField path="phone_number" type="string" required>
Phone number in E.164 format. Example: `+1234567890`
</ParamField>

<ParamField path="agent_id" type="string" required>
ID of the AI agent to handle the call
</ParamField>

<ParamField path="customer_name" type="string">
Name of the person being called. Example: `John Doe`
</ParamField>

<ParamField path="call_purpose" type="string">
Purpose or reason for the call. Example: `Appointment reminder`
</ParamField>

### Response

**200 OK** - Call initiated successfully

<ResponseField name="ctx_id" type="string">
Request context ID
</ResponseField>

<ResponseField name="data" type="object">
  <ResponseField name="call_id" type="string">Call session ID</ResponseField>
  <ResponseField name="status" type="string">Call status</ResponseField>
  <ResponseField name="version" type="string">Used API version</ResponseField>
</ResponseField>

<ResponseField name="message" type="string">
"Request processed successfully"
</ResponseField>

**400 Bad Request** - Invalid request parameters

**401 Unauthorized** - Invalid or missing token

**429 Too Many Requests** - Rate limit exceeded (10 calls per minute)

**500 Internal Server Error** - Server error
