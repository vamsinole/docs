---
title: Get Knowledge Base by ID
api: 'GET https://prod-contactswing-fastapi-962560522883.us-central1.run.app/v2/_knowledgebase/{id}'
description: Retrieve a single knowledge base by its ID via the ContactSwing API.
---

### Authorizations
<ParamField 
  header="Authorization" 
  type="string" 
  required
>
Enter your ContactSwing JWT Bearer token.
</ParamField>

### Path Parameters
<ParamField path="id" type="string" required>
Unique knowledge base identifier from ContactSwing dashboard.
</ParamField>

### Response

**200 OK** - Knowledge base retrieved successfully

<ResponseField name="ctx_id" type="string">
Request context ID
</ResponseField>

<ResponseField name="data" type="object">
Knowledge base details including documents and configuration.
  <ResponseField name="id" type="string">Knowledge base ID</ResponseField>
  <ResponseField name="name" type="string">Knowledge base name</ResponseField>
  <ResponseField name="documents" type="array">Associated documents</ResponseField>
</ResponseField>

<ResponseField name="message" type="string">
"Request processed successfully"
</ResponseField>

### Example Request
```bash
curl 'https://prod-contactswing-fastapi-962560522883.us-central1.run.app/v2/_knowledgebase/YOUR_KB_ID' \
  -H 'Authorization: Bearer YOUR_JWT_TOKEN'
