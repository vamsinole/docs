---
title: Create API Key
api: 'POST https://prod-contactswing-fastapi-962560522883.us-central1.run.app/v2/_api_keys'
description: Create a new API key via the ContactSwing API.
---

### Authorizations
<ParamField 
  header="Authorization" 
  type="string" 
  required
>
Enter your ContactSwing JWT Bearer token.
</ParamField>

### Request Body
**JSON: ApiKeyRequest** (see OpenAPI spec)

<ParamField path="name" type="string" required>
API key display name. Example: `Production SMS Key`
</ParamField>

<ParamField path="description" type="string">
Key purpose/description.
</ParamField>

<ParamField path="permissions" type="array">
Array of allowed permissions/scopes.
</ParamField>

<ParamField path="expires_at" type="string">
ISO 8601 expiration date (optional).
</ParamField>

### Complete Example
```json
{
  "name": "My Production API Key",
  "description": "SMS and Webhook actions only",
  "permissions": ["actions:read", "actions:write", "sms:send"],
  "expires_at": "2026-12-31T23:59:59Z"
}
