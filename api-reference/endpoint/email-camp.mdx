---
title: Create Campaign with Email Touchpoint
api: 'POST https://prod-contactswing-fastapi-962560522883.us-central1.run.app/v2/campaign/create_with_touchpoint'
description: Create a new campaign with an email touchpoint.
---

### Authorizations
<ParamField
  header="Authorization"
  type="string"
  required
>
Enter your ContactSwing JWT Bearer token.
</ParamField>

### Request Body

<ParamField path="name" type="string" required>
Campaign display name
</ParamField>

<ParamField path="type" type="string">
Campaign type.
</ParamField>

<ParamField path="business_goal" type="string">
The business goal of the campaign.
</ParamField>

<ParamField path="touchpoint" type="object" required>
The touchpoint object.
</ParamField>

<ParamField path="touchpoint.name" type="string" required>
The name of the touchpoint.
</ParamField>

<ParamField path="touchpoint.type" type="string" required>
The type of the touchpoint. e.g. `EMAIL`.
</ParamField>

<ParamField path="touchpoint.status" type="string" required>
The status of the touchpoint. e.g. `scheduled`.
</ParamField>

<ParamField path="touchpoint.start_at" type="string" required>
ISO 8601 scheduled date for the touchpoint.
</ParamField>

<ParamField path="touchpoint.assistant_id" type="integer" required>
The ID of the assistant to be used.
</ParamField>

<ParamField path="touchpoint.additional_settings" type="object" required>
Additional settings for the touchpoint.
</ParamField>

<ParamField path="touchpoint.additional_settings.execution_days" type="array" required>
Array of days when the campaign will be executed. e.g. `["mon", "tue"]`
</ParamField>

<ParamField path="touchpoint.additional_settings.start_hour" type="integer" required>
The start hour for the campaign execution.
</ParamField>

<ParamField path="touchpoint.additional_settings.end_hour" type="integer" required>
The end hour for the campaign execution.
</ParamField>

<ParamField path="touchpoint.additional_settings.time_zone" type="string" required>
The timezone for the campaign execution. e.g. `Asia/Kolkata`.
</ParamField>

<ParamField path="touchpoint.additional_settings.email" type="string" required>
The email address to be used.
</ParamField>

<ParamField path="touchpoint.additional_settings.from_emails" type="array" required>
The email addresses from which the emails will be sent.
</ParamField>

<ParamField path="touchpoint.additional_settings.email_medium" type="string" required>
The email medium to be used. e.g. `SEND_GRID`.
</ParamField>

<ParamField path="touchpoint.customer_details" type="array" required>
An array of customer details objects.
</ParamField>

<ParamField path="touchpoint.customer_details.id" type="string" required>
The customer's ID.
</ParamField>

<ParamField path="touchpoint.customer_details.email" type="string" required>
The customer's email address.
</ParamField>

<ParamField path="touchpoint.email_subject" type="string" required>
The subject of the email.
</ParamField>

<ParamField path="touchpoint.email_body" type="string" required>
The body of the email in HTML format.
</ParamField>

### Response

**201 Created** - Campaign created successfully

<ResponseField name="ctx_id" type="string">Request context ID</ResponseField>
<ResponseField name="data" type="object">
  <ResponseField name="id" type="string">Campaign ID</ResponseField>
  <ResponseField name="name" type="string">Campaign name</ResponseField>
  <ResponseField name="status" type="string">Campaign status</ResponseField>
</ResponseField>

**400 Bad Request** - Invalid input
