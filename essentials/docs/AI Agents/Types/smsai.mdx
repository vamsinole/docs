## Step-by-step guide

<Steps>
 <Step title="Access the AI Agent Dashboard">
    Go to the **AI Agent** tab and select **New AI Agent** to start creating your text automation agent.
    <img src="https://storage.googleapis.com/helpsessionvideos/Contactswing/images/1ea.jpg" alt="Access the AI Agent Dashboard" />
  </Step>
 <Step title="Choose Text Agent Type">
    Select **Text** from the agent type options to build a bot for SMS-based interactions and intelligent responses.
    <img src="https://storage.googleapis.com/helpsessionvideos/Contactswing/images/37.jpg" alt="Choose Text Agent Type" />
  </Step>
 <Step title="Configure Your Agent Settings">
    Name your agent and set up the following options:

    - **Name**: Enter a descriptive name (e.g., "My Text AI Agent")
    - **AI Model**: Choose an AI model for generating responses
    - **Action**: Define actions your agent can trigger during conversations (optional)
    - **Prompt**: Enter instructions to guide your agent's behavior

    Click **Next** to proceed.
    <img src="https://storage.googleapis.com/helpsessionvideos/Contactswing/images/38.jpg" alt="Configure General Settings" />
    <img src="https://storage.googleapis.com/helpsessionvideos/Contactswing/images/sms1.jpg" alt="Configure AI Model and Actions" />
    <img src="https://storage.googleapis.com/helpsessionvideos/Contactswing/images/sms2.jpg" alt="Configure Prompt" />


  </Step>
 <Step title="Test Your Agent">
    Send a test message to ensure your Text AI Agent:

    - Responds appropriately to various inputs
    - Follows the defined prompt guidelines
    - Handles different scenarios correctly
    - Maintains a natural conversation flow
  </Step>
</Steps>
