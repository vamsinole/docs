Learn how to monitor and manage your token usage. This guide shows you how to track and optimize your token consumption.

## Understanding the Token Activity Dashboard

Each entry in the token activity log provides the following details:
- **Assistant ID**: The ID of the assistant used
- **Type**: The category of activity (e.g., emails, calls, chats, text, WhatsApp).
- **Classification**: The response classification assigned to the activity.
- **Response Content**: The actual content generated by the AI.
- **Prompt Tokens**: The count of tokens consumed by the input prompt.
- **Response Tokens**: The count of tokens used in the AI's response.
- **Billing Type**: Indicates the billing source ("contactswing" for our API key, or your configured API).
- **Created At**: The timestamp when the activity was generated.

**Pro-Tip:** Clicking on any activity entry will reveal a detailed view containing:
- **Token usage**
- **Prompt messages**
- **Response information**
- **Email content**

> This detailed view allows for in-depth analysis of individual token activities, aiding in usage optimization.
