Learn how to manage and track your call communications effectively. This guide shows you how to use the call inbox features for better call management.
Here's a walkthrough:

<Steps>
  <Step title="Access the Call Inbox section">
    Navigate to the **Call Inbox** section to access your call logs.

    <img src="https://storage.googleapis.com/helpsessionvideos/Contactswing/images/calll.jpg" alt="Call Inbox" />
  </Step>
  <Step title="Search calls in the inbox">
    Utilize the search bar within the Inbox to locate specific calls.

    <img src="https://storage.googleapis.com/helpsessionvideos/Contactswing/images/search.jpg" alt="Search Calls" />
  </Step>
  <Step title="Use filters to find call logs">
    Filter your call logs using these options:

    - **From:** Enter the number from which you received the call.
    - **To:** Input the destination number of the call.
    - **Session ID:** Retrieve logs by entering the session ID.
    - **AI Agent:** Filter entries by selecting a particular agent.
    - **Date:** Filter by date range (From and To).
    - **Status:** Filter by call status:
      - **ALL**
      - **Started:** The call has just begun.
      - **Completed by user:** The user terminated the call.
      - **Busy:** The AI attempted to call, but the user was busy.
      - **Ringing:** The call is in progress and ringing.
      - **Completed by agent:** The agent concluded the call.
      - **No answer:** The AI initiated the call, but there was no response from the user.

    <img src="https://storage.googleapis.com/helpsessionvideos/Contactswing/images/filter.jpg" alt="Filter Calls" />

    The inbox displays various call entries. You can filter, listen to, and sort them by newest or oldest as required.
  </Step>
</Steps>
