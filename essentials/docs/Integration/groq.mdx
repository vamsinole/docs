## Overview

Integrate the Groq API to power your AI agents with high-speed language processing for real-time conversations and interactions.

Learn how to connect and configure Groq with ContactSwing. This guide shows you how to set up and use Groq integration effectively.

Integrate Groq's high-speed inference engine with our platform to unlock exceptional performance for your AI Agents. Groq provides the fastest inference speeds for large language models, making your agents more responsive and efficient. 🚀

# Step-by-step guide

Follow these steps to add the Groq integration:

<Steps>
  <Step title="Go to the Integrations section">
    In your application, go to the **Integrations** section. Here, you can connect various external services, including Groq, to enhance your AI Agents.

    <img src="https://storage.googleapis.com/helpsessionvideos/Contactswing/images/04.jpg" alt="Integrations" />
  </Step>
  <Step title="Select Groq and connect your API key">
    Click the **Groq** integration option to begin connecting your API key. Once connected, you can use Groq's models to power your AI Agents.

    <img src="https://storage.googleapis.com/helpsessionvideos/Contactswing/images/gr.jpg" alt="Groq integration" />
  </Step>
  <Step title="Complete the integration">
    After you enter your API key, the integration is complete. You can now create high-speed, custom AI Agents directly from the Create AI Agents dashboard. ✨
  </Step>
</Steps>
